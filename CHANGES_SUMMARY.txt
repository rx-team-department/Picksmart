DATABASE CHANGES
════════════════════════════════════════════════════════════════════════════════

NEW FIRESTORE COLLECTION: /deals

Fields:
  • id (auto-generated by Firestore)
  • articleId (reference to linked article)
  • productName (string)
  • heroImageURL (Cloudinary URL)
  • originalPrice (number)
  • dealPrice (number)
  • dealBadge (string: "Hot Deal", "Best Seller", "Top Rated", "Budget Pick", "Limited Stock")
  • dealEndsAt (timestamp)
  • darazLink (URL)
  • starRating (number 1-5)
  • category (string: "earphones", "laptops", "mobiles", "gaming", "hometech")
  • views (number, default 0)
  • createdAt (timestamp)

Relationship:
  • Each deal has articleId linking to /articles collection
  • Allows users to "Read Review" from deal card

Sample Query:
  db.collection("deals").where("dealEndsAt", ">", now).orderBy("dealEndsAt", "asc")

SETUP REQUIREMENTS
════════════════════════════════════════════════════════════════════════════════

STEP 1: Cloudinary Setup
  □ Visit https://cloudinary.com
  □ Sign up (free tier: 25GB/month)
  □ Go to Dashboard
  □ Copy Cloud Name
  □ Go to Settings > Upload
  □ Create Upload Preset: "picksmart_uploads"
  □ Make sure it's "Unsigned" for client-side uploads

STEP 2: Update config.js
  □ Open config.js
  □ Replace "YOUR_CLOUD_NAME" with your Cloud Name
  □ Keep uploadPreset as "picksmart_uploads"
  □ Firebase config unchanged

STEP 3: Firebase Firestore
  □ Ensure /deals collection exists (or auto-created on first save)
  □ Update security rules to allow read /deals
  □ Create a test deal to verify

STEP 4: Test
  □ Go to submit.html (password: PickSmart@786)
  □ Create test article with hero image
  □ Toggle "Feature as Deal"
  □ Fill deal fields
  □ Publish and verify on deals.html

TIME REQUIRED: ~15 minutes
