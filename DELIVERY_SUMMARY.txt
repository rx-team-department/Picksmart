🚀 QUICK START (5 MINUTES)
════════════════════════════════════════════════════════════════════════════════

Step 1: Cloudinary Setup
  1. Go to https://cloudinary.com
  2. Sign up (free, 25GB/month)
  3. Note your Cloud Name (dashboard)
  4. Create Upload Preset: "picksmart_uploads"
  
Step 2: Update Code
  1. Open config.js
  2. Replace "YOUR_CLOUD_NAME" with your cloud name
  3. Keep upload preset as is
  
Step 3: Deploy
  1. git commit -am "Update: Cloudinary integration"
  2. git push
  3. Vercel/Netlify deploys automatically
  
Step 4: Test
  1. Go to submit.html (password: PickSmart@786)
  2. Create test article with image
  3. Toggle "Feature as Deal"
  4. Publish and verify on deals.html
  
✅ DONE! Your site is live with v2.0
